# Práctica 00. Iniciación a JavaScript

## Objetivos

En esta práctica he preparado el repositorio del módulo y he tenido una primera toma de contacto con JavaScript.

## Ejercicio 1. Mi primer programa

En el ejercicio uno primero he mostrado varios mensajes por consola con
`console.log()`. Después he creado tres variables con `const` para guardar los datos de un Pokémon: `nombre` (texto), `tipo` (texto) y `nivel` (número). Y las he mostrado.
Por ultimo volvi a declarar las mismas variables con const y he intentado mostrar los datos de otro Pokémon, pero el programa ha dado un error porque no se pueden declarar dos veces las mismas variables con `const`.

## Ejercicio 2. Operaciones básicas

En el ejercicio dos he guardado en variables los datos de un Pokémon: su `nombre`, su
`nivel`, la `experienciaActual` que tenía y la `experienciaGanada` en un combate.
La operación que utiliza el programa es una suma: sumo la experiencia actual y la
experiencia ganada para calcular la `experienciaTotal`. Después muestro por consola la experiencia que tenía, la que ha ganado y la que tiene ahora. Por último he usado una condición con `if` / `else` que comprueba si la experiencia total es mayor o igual que 100 (`experienciaTotal >= 100`). Y si es así, muestro un mensaje por consola indicando que el Pokémon ha subido de nivel. En caso contrario, muestro un mensaje indicando que no ha subido de nivel.

## Conceptos utilizados

- `console.log()`: Muestra información por consola.
- Variable: Un contenedor para almacenar datos.
- Texto: Una secuencia de caracteres.
- Número: Un valor numérico.
- Condición: Una expresión que se evalúa como verdadera o falsa.
